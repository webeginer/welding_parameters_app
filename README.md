## 🚀 Возможности

- Расчёт режимов дуговой(**MMA**), аргонодуговой(**TIG**), полуавтоматической(**MIG/MAG**) сварки плавлением
- Сварные соединения по ГОСТ 14806-80, ГОСТ 5264-80, ГОСТ 14771-76 и ГОСТ 23518-79
- Автоматический выбор ГОСТа в зависимости от метода сварки и металла
- Расчёт тока, напряжения, диаметра электрода, скорости сварки, расхода газа
- Учёт положения шва (нижнее/вертикальное/потолочное)
- Расчёт дополнительных параметров: времени сварки, расхода материалов, электроэнергии

## ⚙️ Установка и запуск

### Требования

- Python 3.11
- pip

### Установка

```
git clone <repository-url>        
cd welding_parameters_app
python -m venv venv

source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install -r requirements.txt
```

### Запуск бэкенда

```
uvicorn backend.app.main:app --reload --port 8000
```

### Запуск фронтенда

```
streamlit run frontend/index_app.py --server.port 8501
```

### После запуска:

Фронтенд: [http://localhost:8501]()
API документация: [http://localhost:8000/docs]()

## 📡 API эндпоинты

|Метод|Эндпоинт|Описание
|:---|:---|:---|
|POST|/api/calculate|Расчёт параметров сварки
|GET|/api/gost/list|Список доступных ГОСТов
|GET|/api/gost/joint-groups|Группы соединений по ГОСТ
|GET|/api/gost/joint-types|Типы соединений по группе
|GET|/api/gost/processes|Способы сварки по ГОСТ

## 💡 Использование

Выберите метод сварки (MMA, TIG, MIG/MAG)
Укажите основной металл
Выберите тип соединения (стыковое, угловое, тавровое, нахлесточное)
Введите толщину и длину шва
При необходимости укажите положение шва
Нажмите «Рассчитать»
